# Miami para Latinos 🇺🇸🌎

Guía de supervivencia bilingüe (español / English) para latinos que llegan a Miami.
PWA instalable, hecha en HTML + JavaScript puro, sin servidor propio. Hermana de Londres, Madrid, Bilbao y Medellín para Latinos.

**Desarrollada por Vibras Positivas HM — Derechos de Autor Reservados**

🔗 https://haroldco45.github.io/miami-para-latinos/

## Datos verificados (octubre 2026)

- Tarifas: guía de Miami-Dade Transit (febrero de 2026); alza a $2.75 aprobada por el Condado para el 1 de enero de 2027 (WLRN, 6 oct 2026).
- Salario mínimo de Florida: $15.00 / hora desde el 30 de septiembre de 2026; $11.98 con propinas.
- TPS: Pew Research (12 ago 2026).
- Visa B1/B2: 185 USD + 250 USD de tarifa de integridad (Infobae, ene 2026). Restricciones de viaje vigentes desde el 1 de enero de 2026.
- Organizaciones y teléfonos: guía de recursos para migrantes de Miami-Dade y sitios oficiales.

## Publicar en GitHub Pages

1. Crea el repositorio `miami-para-latinos` en github.com/haroldco45.
2. Sube los 7 archivos: `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `og-image.png`, `README.md`.
3. Settings → Pages → Branch `main` / root → Save.
4. Conecta el repo en Netlify como `miami-para-latinos` (la vista previa de WhatsApp apunta a miami-para-latinos.netlify.app).
